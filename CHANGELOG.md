# Changelog

Each revision gets a version number. It's shown in the window title and Help > About,
and the installer is named `KanzonasPDF-v<version>-setup.exe` (the zips keep the same name every version).

| 1.6.1 | (this) | Editing stays fast on busy pages. PyMuPDF named each new markup by checking every other markup's name, number by number (adding 2,000 to a page: 24 s), and walked every markup for replies on each delete: kanzonas/pdf_speed.py replaces the naming with a name unique without looking (same prefix) and deletes many markups in one walk (replace_many and Delete use it); Delete checks locks in one walk; a Move reads the selection once; a repaint doesn't read the selected markups again until something changes (selected_models_to_paint); the live CAD highlight takes markups one per step. A markup that is only moved (Move, a nudge, a drag, text moved with its highlights) is moved where it is (annotations.translation / shift_in_place: its /Rect, /Vertices, /L, /QuadPoints, /InkList, /CL, its pop-up's box and the positions kept in KZProps are shifted; its appearance goes along exactly), not deleted and written anew: about 30 times quicker per markup, pixel for pixel the same picture moved (a box drawn by another program no longer grows by its border on each move), and the same markup (its replies, stacking place and selection stay; the markups carried by moved text aren't moved a second time). With 1,000 markups (1.6 -> 1.6.1): add 3.3 -> 0.4 s, move 13.5 -> 0.5 s, delete 3.9 -> 0.3 s, repaint 0.23 -> 0 s. The self-test gains "PyMuPDF speed fixes" (the stand-ins are in use and act as PyMuPDF's own: unique names, replies deleted with their markup; it fails if a PyMuPDF update renames what they replace) and "editing speed budget" (1,000 markups added, moved, deleted; a sheet's 400 labels moved with its lines; the highlight's longest step; a repaint), which fail the Windows build if editing slows down again. tests/test_move_in_place.py: every markup kind, on a plain and a turned page, moved in place pixel for pixel. AGENTS.md: the editing budget, pdf_speed.py and moving in place. |
